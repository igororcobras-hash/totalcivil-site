# Total Civil

Página principal e programas de engenharia civil. Endereço: https://totalcivil.com.br/

- `index.html`: página principal com login único, cadastro, pacotes (R$ 55/programa/mês, 2 meses grátis, indicação 10%), pagamento (Pix/transferência, aviso pelo WhatsApp), pedidos de programa personalizado e painel **Usuários** dos administradores.
- `pavimento/`, `orcamento/`, `intertravado/`, `drenagem/`, `concreto/`, `visitas/`, `manutencao/`: os programas. Todos usam o mesmo login (mesmo endereço = mesma sessão). Sem login, mandam para a página principal; sem liberação no painel Usuários (ou com a validade vencida), ficam bloqueados.
- **Código protegido:** o site publicado não tem o código dos programas. A rotina **Publicar site protegido** (`.github/workflows/publicar-site.yml` + `scripts/publicar/montar-site.js`) roda a cada merge na `main`: envia cada `<programa>/index.html` (gzip, em partes) para o Firestore (`programas/<programa>`) e publica o site com a tela de entrada (`carregador.js`) no lugar de cada programa. As regras (`programas` em `firestore.rules`) só entregam o código a quem tem login e o programa liberado no painel Usuários, sem recusa e dentro da validade. Precisa do segredo `FIREBASE_SERVICE_ACCOUNT` e de Settings › Pages › Source = GitHub Actions. Programa novo: incluir em `PROGRAMAS` (página principal), em `montar-site.js` e em `campoDoPrograma` das regras.
- `acesso-programa.js`: segunda trava, dentro de Drenagem, Concreto e Visitas.
- `firestore.rules`: regras do banco. Ao mudar, cole em Firebase › Firestore Database › Regras › Publicar.
- Os endereços antigos (pavimento./orcamento./intertravado./concreto.totalcivil.com.br) redirecionam para cá.
- `orcamento/dados/`: bancos mensais SINAPI (RJ) e SCO-Rio, um arquivo por mês (nenhum mês é apagado). Gravados pela rotina **Bancos mensais SINAPI e SCO** (`.github/workflows/bancos-mensais.yml` + `scripts/bancos/`), que roda todo dia do dia 3 ao 28, baixa o mês novo da Caixa e da Prefeitura do Rio, confere abas, colunas, Onerado/Desonerado, mês e preços contra o mês anterior, e só grava se tudo bater. Para buscar meses antigos: Actions › Bancos mensais › Run workflow › "desde" = AAAA-MM. No programa, o seletor "📅 Mês" escolhe o mês.
